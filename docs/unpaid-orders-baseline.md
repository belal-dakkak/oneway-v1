# أرشفة نقطة بداية الطلبات غير المسددة

تُخرج الأرشفة الطلبات القديمة من تبويب **طلبات لم يتم سدادها** فقط. لا تغيّر مبالغ الطلبات أو أرصدة الزبائن، ولا تنشئ دفعات أو حركات صندوق. تبقى الطلبات في القائمة العامة وتبقى حسابات الزبائن، بما فيها الحسابات ذات الرصيد صفر، متاحة للتفاصيل وكشف PDF.

## النشر والتنفيذ

نفّذ الترحيلات أولاً:

```text
migrate --force
```

أنشئ تقرير معاينة خاصاً خارج المجلد العام:

```text
orders:baseline-unpaid --output=storage/app/unpaid-orders-baseline.json
```

راجع التقرير، ثم طبّقه دون تعديله:

```text
orders:baseline-unpaid --apply=storage/app/unpaid-orders-baseline.json
```

يلتقط التقرير الطلبات الظاهرة في التبويب لحظة إنشائه فقط. الطلبات الجديدة اللاحقة لا تتأثر. إذا تغير أي طلب موجود في التقرير قبل التطبيق، تتراجع العملية كاملة ويجب إنشاء تقرير جديد. إعادة تطبيق التقرير المنجز آمنة ولا تكرر سجلات الأرشفة.
